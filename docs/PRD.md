# 📄 سند نیازمندی‌های محصول (PRD)
# Personal AI Commercial Studio — استودیوی تبلیغاتی شخصی با هوش مصنوعی

**نسخه:** 1.0 — تیر ۱۴۰۵ (ژوئیه ۲۰۲۶)
**مالک:** استفاده شخصی (بدون فروش به دیگران)

---

## ۱. چه چیزی می‌سازیم؟

یک وب‌اپ شخصی که بدون نوشتن پرامپت، فقط با **فرم و گزینه**، این خروجی‌ها را تولید می‌کند:

| خروجی | توضیح |
|---|---|
| عکس تبلیغاتی محصول | استودیویی، لایف‌استایل، کاتالوگ |
| ریلز اینستاگرام / یوتیوب شورتس | عمودی ۹:۱۶ با سناریوی قلاب → نمایش → CTA |
| تیزر تبلیغاتی | ویدیو سینمایی چندصحنه‌ای |
| ویدیو UGC | با اینفلوئنسر AI فارسی‌زبان، طبیعی و قابل باور |
| ویدیو معرفی محصول / کسب‌وکار | با دیالوگ فارسی |
| AI Influencer | ساخته‌شده از عکس‌های یک شخص واقعی، با حفظ کامل هویت |

**اصل شماره یک سیستم — قفل هویت (Identity Lock):**
چهره، فرم صورت، چشم، بینی، لب، فک، پوست و رنگ و بافت آن، مو و خط رویش، فرم بدن، قد، وزن ظاهری، تناسب اندام، دست‌ها و انگشت‌ها، سن ظاهری و جنسیت **هرگز تغییر نمی‌کنند**. فقط لباس، لوکیشن، نور، زاویه دوربین، ژست، اکسسوری، پس‌زمینه، محصول، سناریو، دیالوگ و حس صحنه قابل تغییرند. این قوانین به‌صورت متنی سخت در هر پرامپت تزریق می‌شوند (`IDENTITY_PRESERVATION_RULES` در `src/lib/promptBuilder.ts`) و در سطح مدل با رفرنس چندعکسی یا LoRA اجرا می‌شوند.

## ۲. معماری کلی

```
انتخاب‌های کاربر (فرم فارسی)
        │
        ▼
┌──────────────────┐     ┌─────────────────────────────┐
│  Prompt Builder   │ ◄── │ کتابخانه‌ها (صحنه/نور/دوربین/سبک) │
│  + Script Builder │ ◄── │ Identity / Product / Brand Manager │
└──────────────────┘     └─────────────────────────────┘
        │  بسته پرامپت JSON (قابل ویرایش)
        ▼
┌──────────────────┐     ┌─────────────────────────────┐
│   Model Router    │ ◄── │ config/models.json (تعویض‌پذیر) │
└──────────────────┘     └─────────────────────────────┘
        │
        ├── fal.ai (تصویر، ویدیو، لب‌خوانی، آموزش LoRA، آپ‌اسکیل)
        ├── ElevenLabs / MiniMax (صدای فارسی، کلون صدا)
        ▼
┌──────────────────┐
│  Output Manager   │ → ذخیره خروجی + پرامپت + چک‌لیست QC
└──────────────────┘
```

**اصل ماژولار بودن:** هیچ کدی به مدل خاصی وابسته نیست. نگاشت «وظیفه ← مدل» فقط در `config/models.json` است. وقتی مدل بهتری آمد، فقط همان فایل عوض می‌شود.

## ۴. استراتژی حفظ هویت (مهم‌ترین تصمیم فنی)

بر اساس تحقیق ژوئیه ۲۰۲۶، دو روش وجود دارد و ما **هر دو را به‌صورت پلکانی** پیاده کرده‌ایم:

**سطح ۱ — رفرنس چندعکسی (بدون آموزش، همین امروز کار می‌کند):**
عکس‌های مرجع شخص (تا ۱۴ عکس) مستقیم به مدل **Nano Banana Pro** (Gemini 3 Pro Image) داده می‌شوند که «قفل هویت» داخلی دارد. کیفیت عالی، ولی در تولید انبوه ~۵-۱۵٪ رانش چهره دارد.

**سطح ۲ — آموزش LoRA (استاندارد طلایی، یک‌بار برای هر نفر، ~۲ تا ۸ دلار):**
از عکس‌های واقعی، یک دیتاست ۲۰-۶۰ عکسی متنوع ساخته می‌شود و یک **LoRA روی FLUX.2** آموزش می‌بیند. LoRA علاوه بر چهره، **فرم بدن و تناسب اندام** را هم یاد می‌گیرد و در صدها تولید ثابت می‌ماند. بعد از ثبت آدرس LoRA در پروفایل شخص، Model Router خودکار از مسیر قوی‌تر استفاده می‌کند.

**جریان توصیه‌شده:** شروع با سطح ۱ → وقتی از شخصی زیاد استفاده کردی، LoRA آموزش بده (سطح ۲).

برای **محصول** هم همین منطق: رفرنس چندعکسی با Nano Banana Pro Edit / Seedream Edit؛ و برای لیبل‌های ریز، کامپوزیت لیبل واقعی در فاز ۲.

### صدا و لب‌خوانی فارسی
| کاربرد | مدل پیش‌فرض | نکته حیاتی |
|---|---|---|
| گفتار فارسی | **ElevenLabs v3** | فقط v3 فارسی دارد — Multilingual v2 و Flash فارسی ندارند! |
| گفتار ارزان + کلون صدا | MiniMax Speech 2.5/2.6 HD (روی fal) | کلون صدا با فقط ۱۰ ثانیه نمونه، ~یک‌سوم قیمت |
| عکس→ویدیو سخنگو | **OmniHuman 1.5** ($0.16/s) | مدل‌های لب‌خوانی audio-driven زبان‌مستقل‌اند — فارسی عالی |
| دوبله ویدیوی موجود | sync.so lipsync-2 | LatentSync برای حجم بالا (تقریباً مجانی) |

### کنترل کیفیت
CodeFormer (ترمیم چهره) → Recraft Crisp / Aura SR (آپ‌اسکیل تمیز) → SeedVR2 (ویدیو) — همه روی fal با هزینه چند سنت.

### چرا fal.ai به‌عنوان دروازه اصلی؟
تنها پلتفرمی که **همه** موارد بالا را با **یک API Key** دارد: تصویر + ویدیو + لب‌خوانی + TTS فارسی + آموزش LoRA + آپ‌اسکیل. Replicate (کلادفلر) مکمل خوبی برای مدل‌های متن‌باز است.

## ۶. ورودی‌ها و خروجی‌ها

**ورودی‌های کاربر در فرم:** نوع خروجی، شخص، محصول، برند، صحنه، سبک، نور، نمای دوربین، حرکت دوربین، پلتفرم (ریلز/استوری/پست/شورتس/یوتیوب/بنر/بیلبورد)، مدت، لحن، CTA، توضیح آزاد.

**خروجی سیستم:**
1. **بسته پرامپت JSON** (`PromptPackage`) — شامل پرامپت نهایی، negative prompt، قوانین حفظ هویت، سناریوی صحنه‌به‌صحنه، دیالوگ فارسی، تنظیمات مدل. حتی **بدون هیچ API Key** ساخته می‌شود و قابل کپی در هر ابزاری است.
2. **فایل خروجی واقعی** (عکس/ویدیو) اگر کلید fal تنظیم شده باشد.
3. **رکورد ذخیره‌شده** در Output Manager با چک‌لیست QC.

## ۸. نقشه راه

**فاز ۰ — MVP (همین نسخه):** همه ۱۵ ماژول به شکل پایه؛ تولید عکس هویت‌دار، ریلز، بسته پرامپت، QC دستی.

**فاز ۱ — صدا و UGC کامل:**
- دکمه «تولید صدا» روی دیالوگ‌ها (API آماده است) + پخش صوت در UI
- خط لوله UGC یک‌کلیکی: عکس هویت‌دار → OmniHuman → ویدیو سخنگوی فارسی
- کلون صدای شخص (MiniMax / ElevenLabs IVC)
- دکمه «آموزش LoRA» داخل Identity Manager (endpoint آماده است)

**فاز ۲ — کیفیت و اتوماسیون:**
- QC خودکار: مقایسه چهره خروجی با رفرنس توسط مدل Vision + face-similarity
- نویسنده هوشمند سناریو با Claude API (به‌جای قالب‌ها)
- کامپوزیت خودکار لوگو/لیبل واقعی روی خروجی
- آپ‌اسکیل خودکار خروجی‌های نهایی

**فاز ۳ — راحتی:**
- صف تولید انبوه (چند خروجی همزمان)، تقویم محتوا، خروجی مستقیم به فرمت هر پلتفرم
