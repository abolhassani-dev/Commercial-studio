# 🚀 راه‌اندازی در ۱۰ دقیقه

## قدم ۱ — نصب Node.js
اگر نداری، از [nodejs.org](https://nodejs.org) نسخه LTS (20 یا بالاتر) را نصب کن. (نصبش مثل هر برنامه معمولی است — Next بزن تا تمام شود.)

## قدم ۲ — دانلود و نصب پروژه
```bash
git clone https://github.com/abolhassani-dev/Commercial-studio.git
cd Commercial-studio
npm install
```

## قدم ۳ — کلیدهای API (اختیاری ولی برای تولید واقعی لازم)
```bash
cp .env.example .env.local
```
بعد فایل `.env.local` را با یک ویرایشگر باز کن و کلیدها را بگذار:
- `FAL_KEY` از [fal.ai/dashboard/keys](https://fal.ai/dashboard/keys) — حساب بساز، ~$10 شارژ کن، کلید بساز.
- `ELEVENLABS_API_KEY` از [elevenlabs.io](https://elevenlabs.io) (برای صدای فارسی).

## قدم ۴ — اجرا
```bash
npm run dev
```
حالا در مرورگر برو به **http://localhost:3000** 🎉

## قدم ۵ — اولین خروجی (۵ دقیقه)
1. **افراد** → شخص را با ۱۰ عکس مرجع و توصیف ظاهری اضافه کن.
2. **محصولات** → محصول را با ۳-۶ عکس ثبت کن.
3. **ساخت محتوا** → «عکس تبلیغاتی» + شخص + محصول + صحنه «نمایشگاه» + سبک «لوکس» → **ساخت پرامپت** → **تولید خروجی واقعی**.
4. خروجی در **خروجی‌ها** ذخیره شده؛ چک‌لیست QC را پر کن. اگر چهره کمی فرق داشت، دوباره تولید کن (هر تولید نتیجه متفاوتی دارد) یا در آینده LoRA آموزش بده.

## عیب‌یابی سریع
| مشکل | راه حل |
|---|---|
| «FAL_KEY تنظیم نشده» | فایل `.env.local` را ساختی؟ بعد از تغییر، `npm run dev` را ری‌استارت کن |
| خطای ۴۰۳/موجودی از fal | حسابت را شارژ کن |
| مدل پیدا نشد (404 از fal) | شناسه مدل در `config/models.json` را با [fal.ai/models](https://fal.ai/models) تطبیق بده — مدل‌ها گاهی نسخه جدید می‌گیرند |
| چهره شبیه نیست | عکس‌های مرجع بیشتر و باکیفیت‌تر اضافه کن؛ توصیف قفل‌شده را دقیق‌تر بنویس؛ در نهایت LoRA آموزش بده |
