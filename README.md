# 🎬 Personal AI Commercial Studio — استودیوی تبلیغاتی شخصی

سیستم شخصی تولید محتوای تبلیغاتی با هوش مصنوعی: **عکس تبلیغاتی، ریلز، تیزر، ویدیو UGC و AI Influencer فارسی‌زبان** — بدون نوشتن پرامپت، فقط با فرم و گزینه.

## ویژگی‌های کلیدی
- 🔒 **قفل هویت** — از عکس‌های یک شخص واقعی، اینفلوئنسر AI می‌سازد بدون کوچک‌ترین تغییر در چهره، بدن، پوست و مو
- 📦 **ثبات محصول** — محصول واقعی (موتورسیکلت، لباس، کیف…) عیناً در هر صحنه‌ای جای‌گذاری می‌شود
- 🧩 **معماری ماژولار** — تعویض مدل فقط با ویرایش `config/models.json`؛ هیچ وابستگی به مدل خاص
- 🇮🇷 **فارسی‌محور** — رابط RTL فارسی، سناریو و دیالوگ UGC فارسی، گفتار فارسی (ElevenLabs v3 / MiniMax)
- 📋 **بدون کلید API هم کار می‌کند** — بسته پرامپت آماده می‌سازد تا در هر ابزاری paste کنی

## شروع سریع
```bash
npm install
cp .env.example .env.local   # کلیدها را داخلش بگذار (اختیاری)
npm run dev                  # → http://localhost:3000
```
راهنمای کامل: [`docs/SETUP.md`](docs/SETUP.md)

## ساختار پروژه
```
config/models.json        ← Model Router: نگاشت وظیفه→مدل (نقطه تعویض مدل‌ها)
data/libraries/           ← کتابخانه صحنه/نور/دوربین/سبک/پلتفرم (قابل گسترش)
data/store/               ← داده‌های تو: افراد، محصولات، برندها، خروجی‌ها (در گیت نیست)
src/lib/promptBuilder.ts  ← ساخت پرامپت + قوانین قفل هویت
src/lib/scriptBuilder.ts  ← سناریوی چندصحنه‌ای + متن UGC فارسی
src/lib/modelRouter.ts    ← اجرای تولید با مدل مناسب هر وظیفه
src/lib/providers/        ← اتصال fal.ai و ElevenLabs (ارائه‌دهنده جدید = یک فایل جدید)
src/lib/qc.ts             ← چک‌لیست کنترل کیفیت
src/app/                  ← رابط کاربری فارسی (داشبورد، افراد، محصولات، برند، ساخت، خروجی‌ها)
```

> این پروژه برای استفاده شخصی است. برای ساخت محتوا از چهره افراد واقعی، حتماً رضایت آن‌ها را داشته باش.
